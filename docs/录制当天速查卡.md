# 录制当天速查卡（打印或截图备用）

## 开机三件事

```
1. 双击 D:\比赛4\yingzao\启动.bat → 输入 1（演示模式）→ 浏览器自动打开
2. 登录账号：木作学徒 / 5678（首次使用需先注册——无预置账号，账号存在本机浏览器）
3. F11 全屏 → Win + G → 点录制（或 Win + Alt + R）
```

## 一镜到底操作单（总长约 2 分 30 秒，配合词稿旁白）

| 时间 | 做什么 |
|---|---|
| 0:00–0:10 | 登录门停留（什么都不点，让镜头拍封面） |
| 0:10–0:25 | 输入 木作学徒 / 5678 → 进入 |
| 0:25–0:50 | 学堂：拖拽旋转两圈 → 点「栌斗」看考据卡 → 拆解滑杆拉到 100 再拉回 |
| 0:50–1:15 | 拼装挑战：新手教学开 → 开始拼装 → 连点构件盘（15 件自动落位） |
| 1:15–1:35 | 参数工坊：材等滑杆 三等 → 一等（看数字变化） |
| 1:35–1:55 | 榫卯谱：抱肩榫开合 → 楔钉榫两步 |
| 1:55–2:35 | 斗栱抗震：**先「刚性连接」大震 → 切「斗栱连接」**（最强对比） |
| 2:35–2:50 | 营造之旅：17 秒大殿落成，日暮收尾 |
| 2:50–3:00 | 停留日暮全景 → Win + Alt + R 停止录制 |

## 录完之后

- 视频在 `视频捕获` 文件夹（Win+G 默认位置）
- 按《演示视频词稿》配旁白 → 剪辑 → 输出 MP4 1080p
- 报名表链接填：https://yingzao.pages.dev/
- 团队/教师信息：已填入文档与 PPT（《大木作》团队 · 指导教师 段欣妤、陈超 · 南昌航空大学科技学院）

## 出问题怎么办

| 问题 | 处理 |
|---|---|
| 页面打不开 | 双击 `大木作-离线单文件版.html`（零依赖），或开 `启动.bat` 本地演示 |
| 录制时画面卡 | 关掉其他程序；浏览器 F11 全屏重试 |
| 抗震不动 | 确认点过「开始震动」，震级选「大震」 |
| 拼装点了没反应 | 确认开了「新手教学」开关 |
