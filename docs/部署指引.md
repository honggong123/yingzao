## 常见问题排查

| 现象 | 原因 | 解决 |
|---|---|---|
| pages.dev 打不开 | 地区网络对该域名的解析波动 | 手机流量测试；或用离线包 |
| 链接能开但点"进入"没反应 | 浏览器禁用了 localStorage（隐私模式） | 换普通模式 |
| 三维画面卡顿 | 集显/低配设备 | 缩小浏览器窗口；关闭其他标签页；移动端本就会降档 |
| 抗震演示没有震动 | 未点"开始震动"，或振幅滑杆为 0 | 点按钮；预设选"中震"以上 |
