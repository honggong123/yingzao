# 《大木作》演示视频词稿

> 用途：参赛演示视频旁白录制。全程约 3 分钟。
> 使用说明：按段落录制即可，每段独立成条，删改方便。
> 建议语速：**每段旁白都留了余量**，读完即可，不要赶。
> 录制顺序：先用浏览器录屏（Chrome 全屏，1920×1080），再按段落配旁白。

---

## 录屏最简方法（Windows 自带，零安装）

1. 双击项目根目录 **`启动.bat`**，输入 `1`（演示模式）回车——浏览器会自动打开作品
2. 按 **F11** 全屏，按 **Win + G** 打开 Xbox Game Bar（Windows 自带）→ 点录制按钮（或 **Win + Alt + R**）
3. 按《录制清单》分段操作；再按 **Win + Alt + R** 停止，视频自动存到 `视频捕获` 文件夹
4. 录完把片段交给剪辑软件拼起来配旁白即可

> 备选：OBS Studio（免费，功能更强）；或浏览器扩展（如 Loom）。任何录屏工具都行，关键是 1080p + 全屏。

## 0:00–0:15 ｜ 开场（登录门）

**画面**：登录门全屏——墨色背景，"大木"朱印、标题"大木作 · 数字营造系统"、"宋《营造法式》斗栱榫卯"副题。
**动作**：光标输入用户名"木作学徒"→ 点"进入大木作"→ 门开，进入主界面。

**旁白**：
> 八百年前，宋人李诫写下一部《营造法式》，用一套"材分制"，规定了木构建筑从斗栱到殿宇的全部尺度。今天，我们把它的算法重新写了一遍。（停顿）欢迎来到《大木作》。

---

## 0:15–0:50 ｜ 营造学堂（考据）

**画面**：营造学堂展区，一朵四铺作柱头铺作居中。
**动作**：① 拖动画面旋转一圈 → ② 点击"栌斗"标注，左下角考据卡出现 → ③ 拖"拆解"滑杆从 0 到 100%，铺作层层解体 → ④ 拖回 0。

**旁白**：
> 屏幕上是一朵由材分制算法实时生成的四铺作柱头铺作。材广十五分、厚十分，足材二十一分，华栱每跳出跳三十分——这里出现的每一个数字，都能回答出处是《营造法式》的哪一卷。（停顿）点击任意构件，读它的形制与考据；拖动拆解滑杆，看它一层层解开——普拍枋、栌斗、华栱、泥道栱、令栱、橑檐槫，受力正沿着这条路径，一层层传回柱身。

## 0:50–1:10 ｜ 拼装挑战（互动）

**画面**：拼装挑战展区，新手教学模式（单卡）。
**动作**：连点三件正确构件，看飞入落位；**有意点一次错误卡**（晃动），然后继续。

**旁白**：
> 认识之后，亲手拼一遍。构件盘里是这朵铺作的全部构件，用户要按真实的营造工序，从下往上选出下一件——选对，它会飞回原位，发出木质的咔哒声；选错，它会晃动。（停顿）铺作不语，次序自明——这是古人的工程逻辑，也是游戏中唯一的规则。

---

## 1:10–1:35 ｜ 参数工坊（模数化）

**画面**：参数工坊展区，六铺作重栱。
**动作**：材等滑杆从"三等"拖到"一等"——铺作整体放大；面板数字变化（每分 18.7 厘米、通高 410 厘米）。

**旁白**：
> "凡构屋之制，皆以材为祖"——材有八等，度屋之大小，因而用之。（停顿）拖动滑杆切换材等，同一朵铺作的体量随之变化：一等材用于九到十一间的殿身，八等材用于亭榭。同一套比例，八种房子——这不是历史名词，这是八百年前的参数化设计引擎。

---

## 1:35–1:55 ｜ 榫卯谱（连接之美）

**画面**：榫卯谱展区。
**动作**：选"抱肩榫"→ 开合滑杆从 0 拉到 100%，两枋弧口相抱、圆柱落下；再切"楔钉榫"，演示"先合体、再上销"两步。

**旁白**：
> 斗栱之外，另一种智慧藏在连接里。抱肩榫以弧形凹口把圆柱"抱"在怀中；楔钉榫让两段弧材互搭成钩，再加一枚楔销锁死。（停顿）六种榫卯，没有一颗钉子——古人把木头的性格，摸得比我们透。

---

## 1:55–2:30 ｜ 斗栱抗震（高潮）

**画面**：斗栱抗震展区，振动台。
**动作**：① 预设"大震"→ ② 选**"刚性连接"** → 点"开始震动"（屋面狂甩，示波器双轨迹，减震 0%）→ ③ 切**"斗栱连接"**（屋面明显平稳，减震 67%）→ ④ 停留两秒让数字被看清。

**旁白**：
> 斗栱不只是装饰，它是古建筑的抗震装置。（停顿）同一场"大震"：刚性连接下，屋面剧烈甩动，响应被放大到一点三倍——示波器上这条亮线几乎失控。切换到斗栱连接——（停顿）地震能量在铺作的层层错动里被摩擦耗掉，屋面响应衰减到三分之一，减震百分之六十七。（停顿）应县木塔近千年不倒、晋祠圣母殿历经大震，靠的就是这套耗能智慧。

---

## 2:30–2:55 ｜ 营造之旅（终章）

**画面**：营造之旅展区，17 秒游走全片。
**动作**：不干预，让镜头走完：台基 → 立柱 → 铺作阵 → 举折屋顶 → 日暮全景。

**旁白**：
> 最后，把学到的一切，还给它本来的样子。筑台基、立柱架阑额、施铺作、举折成顶——十七秒，一座庑殿大殿从无到有。（停顿，等日暮画面）殿上十八朵铺作、整座屋架与瓦垄，全部由算法实时生成。日暮，殿成，不用一钉一铆。

# 录制清单（给录制者）

## 录屏准备
- [ ] 浏览器全屏（F11），分辨率 1920×1080，隐藏书签栏
- [ ] 用 `npm run build` 产物或线上地址演示（**不要用 dev 服务器**，避免 HMR 干扰）
- [ ] 先演练一遍完整流程，确认每个展区加载正常
- [ ] 关上系统通知（勿扰模式）

## 录屏分段（建议每段单独录，方便补录）
1. 登录门 → 进入（15s）
2. 学堂：旋转 + 点考据 + 拆解滑杆往返（35s）
3. 拼装：新手教学连拼 3 件 + 故意点错 1 次（20s）
4. 工坊：材等滑杆三等 → 一等（25s）
5. 榫卯：抱肩榫开合 + 楔钉榫两步（20s）
6. 抗震：**刚性大震 → 斗栱连接对比**（35s，最关键的一段，可多录几条挑最好的）
7. 营造之旅：全程不干预（17s）
8. 日暮全景停留（10s）

## 旁白录制
- 手机或电脑麦克风均可，安静环境，与屏幕距离约 20 厘米
- 每段读 2–3 遍，挑选最自然的一条
- 语气建议：**讲述感而非播音腔**，停顿处真的停一下

## 剪辑合成
- 视频轨：录屏按时间轴拼接，节奏对齐旁白
- 关键数据加字幕强调：**"减震 67%"、"足材 21 分"、"每跳 30 分"**
- 背景音乐：建议用极轻的古琴/环境音（音量 -24dB 以下，不盖旁白）
- 输出：MP4 / H.264 / 1080p / 总长约 3 分 10 秒
- 若赛事限时 3 分钟：压缩"榫卯谱"段至 10s、日暮停留减至 5s
