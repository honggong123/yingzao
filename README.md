# 大木作 · DAMUZUO

**《营造法式》斗栱榫卯数字营造系统** —— 全国大学生数字媒体科技作品及创意竞赛参赛作品。

> **线上演示**：https://yingzao.pages.dev/

把宋《营造法式》的斗栱与榫卯，做成一座**可拆、可拼、可改、可造**的数字营造系统：用户不是"看"非遗，而是亲手参与非遗。

## 启动方式

### 方式零：线上链接（无需安装）

直接打开 **https://yingzao.pages.dev/**

### 方式一：双击 `启动.bat`（推荐，无需记忆命令）

双击项目根目录的 **`启动.bat`**，按菜单提示输入数字回车即可：

| 选项 | 模式 | 说明 |
|---|---|---|
| `1` | 演示模式 | 构建生产版本并启动（端口 4173）——最接近线上效果，**答辩演示、录制视频用这个** |
| `2` | 开发模式 | 带热更新（端口 5174），改代码即时生效 |
| `3` | 离线模式 | 直接用已构建的版本启动，**无需联网**——现场答辩无网时用 |
| `4` | 退出 | |

启动后浏览器会自动打开。**关闭黑色窗口即停止服务。**

首次运行会自动安装依赖（需要 Node.js，未安装时脚本会给出提示）。

### 方式二：命令行

```bash
npm install
npm run dev        # 开发模式 → http://localhost:5174
npm run build      # 构建生产版本到 dist/
npm run preview    # 预览生产版本 → http://localhost:4173
```

> 现场答辩建议用**方式一的演示模式或离线模式**（生产版本），不要用开发模式——开发模式的性能表现与热更新机制与线上不同。

## 架构

```
src/
├── core/          units.ts 材分制 | wood.ts 程序化木纹 | scene.ts 渲染管线
├── bofa/          营造法式构件系统
│   ├── kaogu.ts   考据词条（每个数字都有出处）
│   ├── dou.ts     斗生成器（栌斗/交互斗/散斗/齐心斗）
│   ├── gong.ts    拱生成器（华拱/泥道拱/瓜子拱/令拱/慢拱，含卷杀）
│   └── puzuo.ts   铺作生成算法
└── components/    Viewer3D.vue（3D 视图 + 标注 + 拾取）
```

## 形制数据基准（均标注于界面考据卡）

- 材广 15 分 × 厚 10 分；栔 6 分；足材 21 分（《营造法式》卷四）
- 每跳 30 分；材分八等（一等 9×6 寸 …… 八等 4.5×3 寸）
- 拱长：泥道拱 63 / 瓜子拱 62 / 令拱 72 / 慢拱 92 分（M2 对照原文核验）
